# 🚀 Incident Batch Processor

Sistema de processamento automatizado de incidentes/logs utilizando Python, Regex e JSON.

O projeto simula um pipeline real de monitoramento e observabilidade, realizando:

- leitura de múltiplos arquivos
- parsing de logs
- extração de padrões
- classificação de severidade
- geração de saída estruturada

---

# 📂 Estrutura do Projeto

```bash
incident_batch_processor/
│
├── incidentes/
│   ├── incidentes1.txt
│   ├── incidentes2.txt
│
├── parser.py
├── main.py
└── README.md
```
